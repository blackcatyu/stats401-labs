Lab 5: Interactive Network Visualization

A synthetic urban transit network of 50 stations across five districts, joined by 50 direct routes. Stations carry three variables (district, daily_passengers, station_type); routes carry two (travel_time_min, route_type). The same data is shown two ways below: a force-directed node-link diagram and an adjacency matrix.

Part A — Node-link diagram

Drag any station to pull the layout apart. Hover a station to isolate it, its routes, and its direct neighbours; hover a route for its details.

District — node colour
Route type — link colour
Station type — node outline
Daily passengers — node size
Travel time — link width

Design of the node-link diagram

District is nominal, so it takes the node fill colour — the natural channel for unordered categories, and it lets district groupings emerge from the force layout. Daily passengers is a ratio quantity, mapped to node radius on a square-root scale so that circle area is proportional to volume; this matches the transit intuition that a busier station is a “bigger” place. Station type uses the node outline rather than a third colour or a shape, keeping every node a circle so the size comparison stays honest: Terminal gets a heavy stroke, Transfer a concentric ring (echoing the interchange symbol on real transit maps), Local a thin stroke. Travel time drives link width (thicker = slower), and route type drives link colour. Dragging separates the dense main chain; hovering fades everything except the focused station, its links and its neighbours, making local structure legible inside the hairball; tooltips report exact values.

Part B — Adjacency matrix

Each filled cell is a direct route. Cell colour = route type, cell opacity = travel time (fainter is quicker). Re-order the rows and columns:

Design of the adjacency matrix

Rows and columns are the 50 stations; a filled cell marks a direct route. The matrix is drawn symmetrically (both triangles) so a block reads the same along either axis. Both link variables carry over from Part A: cell colour repeats the route-type palette and cell opacity encodes travel time. The default row/column order groups stations by district (then by station number), with black dividers and a district colour strip on each axis, so district-to-district connectivity becomes visible as blocks. Two alternate orderings are offered: by degree, which floats the hub stations to the top-left, and by station ID, which matches the raw file and makes the main chain appear as the super-diagonal.

Part C — The six network questions

  1. Which stations appear central in the network? Fourteen stations have three links each (s4, s7, s10, s13, s16, s18, s21, s23, s25, s29, s31, s33, s34, s38); every one is a junction where a cross-district route meets the main chain. s31, s23 and s7 lie on the most shortest paths and read as the strongest hubs.
  2. Which districts are strongly connected to one another? Because stations were assigned to districts in strict rotation, 48 of 50 routes are cross-district and the off-diagonal blocks are all lightly and roughly equally populated: no district pair stands out. The diagonal blocks are nearly empty — almost no within-district routes.
  3. Where are transfer or terminal stations located in the topology? Transfer (ring) and Terminal (heavy stroke) stations are spread evenly along the chain, not clustered — the two types alternate with Local down the line. Terminals are not only at the ends; the true topological ends are the degree-1 stations (s44, s45, s47, s50) and the five completely isolated stations (s42, s43, s46, s48, s49).
  4. Which stations have high passenger volume? Passenger volume climbs monotonically with station number (about 1,400 at s1 to 9,850 at s50), so the largest circles are the high-numbered stations — several of which (s42–s50) are exactly the poorly connected or isolated ones: high demand, thin connectivity.
  5. Where are the longest direct travel-time connections? The three longest routes are all long cross-chain links and all Express: s7–s31 (16 min), s18–s34 (15 min), s29–s50 (14 min). The 2–4 min links are all single steps along the main chain.
  6. Are particular route types concentrated in particular parts of the network? Route type also cycles (Metro / Express / Shuttle repeating), so all three appear in every district and along the whole chain, with no spatial concentration. The only real pattern: the longest cross-links are disproportionately Express.
